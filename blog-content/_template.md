Start writing here. This first paragraph is your intro — keep it short and make
the reader want to keep going.

## Use a heading like this for a new section

Write normal paragraphs just like this one. Leave a blank line between
paragraphs — that's how the page knows where one ends and the next begins.

You can make text **bold like this** or *italic like this*. You can also
[link to another page](https://donttellmama.in/the-commons.html) by putting
the link text in square brackets and the URL in parentheses right after.

### A smaller heading, for a sub-point

Use "###" instead of "##" when you want a smaller heading inside a section.

A bulleted list looks like this:

- First point
- Second point
- Third point

A pull-quote looks like this:

> A short, punchy line you want to stand out from the rest of the text.

## Wrapping up

End with a short closing paragraph, and if it makes sense, a nudge toward
reserving a table or checking out The Commons.
