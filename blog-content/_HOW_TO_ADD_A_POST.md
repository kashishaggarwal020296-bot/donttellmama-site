# How to add a new blog post (no coding needed)

This takes about 10 minutes once you're used to it. You never touch any
code — you just write in a simple text file and upload it.

## Step 1 — Write your post

1. Open the `_template.md` file in this folder (`blog-content`) on GitHub.
2. Copy its contents into a new text file on your computer (Notepad, TextEdit,
   Google Docs saved as plain text — anything works).
3. Fill in the three lines at the top:
   - `title:` — the post's headline
   - `description:` — one or two sentences for Google search results
   - `date:` — today's date, written as `2026-11-14` (year-month-day)
4. Write your post below that. A few things to know:
   - Leave a blank line between paragraphs.
   - Put `##` before a line to make it a heading (like "First, figure out
     your guest count" in the example posts).
   - Put `**` around a word to make it **bold**.
   - Make a bullet list by starting a line with `- `.
   - Delete the "HOW TO PUBLISH THIS" instructions at the bottom of the
     template before you upload — that part is just for you, not for the
     website.
5. Save the file with a short, lowercase, dash-separated name ending in
   `.md` — for example: `best-cocktails-for-a-first-date.md`

## Step 2 — Upload it

1. Go to: https://github.com/kashishaggarwal020296-bot/donttellmama-site/upload/main/blog-content
2. Drag your `.md` file into the upload box.
3. Scroll down, type a short message like "Add new blog post" in the box,
   and click the green **Commit changes** button.

## Step 3 — Wait about a minute

The website rebuilds itself automatically. After roughly a minute, your
post will be live at `donttellmama.in/blog/` — no further action needed
from you.

## If something looks wrong

Send a screenshot to Kashish / whoever manages the site. The most common
issue is a typo in the three lines at the top of the file (`title:`,
`description:`, `date:`) — if the date isn't in `2026-11-14` format, or
those lines got deleted by accident, the post won't show up.
